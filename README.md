# Vhec & Ton: Anniversary Scrapbook

This is a static website that can be hosted free with GitHub Pages.

## Publish with GitHub Pages

1. Create a new public GitHub repository, for example `vhec-and-ton`.
2. Upload `index.html`, the complete `photos` folder, and the complete `audio` folder to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. Wait a few minutes. The website will appear at `https://YOUR-USERNAME.github.io/vhec-and-ton/`.

Keep both the `photos` and `audio` folders beside `index.html`. Moving or renaming them will break the pictures or music.

The song begins after the visitor presses **Open our scrapbook**. Browsers require that first tap before they allow a webpage to play audio.
